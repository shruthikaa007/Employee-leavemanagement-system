# Employee Leave Management System Testing

## 📌 Project Overview

The **Employee Leave Management System Testing** project focuses on automating the testing of an HRMS web application using Selenium WebDriver, Java, TestNG, and Maven.

The project verifies important functionalities such as user login, dashboard access, leave balance verification, leave request form validation, leave type selection, date validation, leave status, leave history, and logout.

The automation framework follows the **Page Object Model (POM)** design pattern to improve code reusability, readability, and maintainability.

## 🎯 Objectives

- Automate the testing of employee leave management functionalities.
- Verify valid and invalid login scenarios.
- Check leave balance and leave request form functionality.
- Validate leave types and date inputs.
- Verify leave status and leave history displays.
- Generate test execution reports using TestNG.
- Reduce repetitive manual testing efforts.

## 🧪 Modules Tested

1. **Login Testing** – Verifies login with valid and invalid credentials.
2. **Dashboard Testing** – Checks whether the dashboard is displayed after login.
3. **Leave Balance Verification** – Checks the displayed leave balance information.
4. **Leave Request Form** – Verifies that the leave request form is accessible.
5. **Leave Type Selection** – Tests the selection of a leave type.
6. **Leave Submission** – Checks the leave request submission workflow.
7. **Invalid Date Validation** – Tests a leave request with an invalid date range.
8. **Leave Status Verification** – Checks the displayed leave status information.
9. **Leave History Verification** – Checks the leave history or its empty state.
10. **Logout Testing** – Tests the logout workflow.

## ⚙️ Prerequisites

Install the following before running the project:

- Java Development Kit (JDK)
- Apache Maven
- Google Chrome browser
- Eclipse IDE or Visual Studio Code
- Internet connection to access the application and download Maven dependencies

Verify Java and Maven installation:

```bash
java -version
mvn -version
```

## ▶️ How to Run the Project

### Step 1: Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### Step 2: Navigate to the project folder

```bash
cd EmployeeLeaveManagementTesting
```

### Step 3: Run the test suite

```bash
mvn clean test
```

Maven downloads the required dependencies, compiles the test code, and executes the tests configured in the project.

**Important:** If your project uses a `testng.xml` suite file, run it according to the configuration in your `pom.xml`, or execute the suite directly through TestNG in your IDE.

## 📊 Test Results

The test suite covers the main login and leave management workflows.

The results can be reviewed in the Maven console and TestNG reports. The exact number of passed, failed, and skipped tests depends on the latest execution.

The default TestNG report is generally available at:

```text
target/surefire-reports/index.html
```

Open the report in a browser after running the tests, if it was generated by your Maven configuration.

## 🏗️ System Architecture

```text
Tester
   ↓

   ↓

   ↓
Google Chrome Browser
   ↓
Orbit HRMS Web Application
```

Maven manages project dependencies and supports test execution, while TestNG handles test execution, assertions, and reporting.
